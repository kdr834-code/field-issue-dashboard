# 새 계정 · 새 세션에서 이어가기

다른 계정이나 다른 PC에서 이 프로젝트를 이어받을 때 쓰는 문서입니다.
**이 파일 하나만 보고 따라 하면 됩니다.**

---

## 1단계 — 받기

```bash
git clone https://github.com/kdr834-code/field-issue-dashboard.git
cd field-issue-dashboard
```

받은 폴더에서 Claude Code를 엽니다. `CLAUDE.md`는 **자동으로 읽히므로**
작업 규칙을 따로 설명할 필요가 없습니다.

## 2단계 — 첫 메시지

아래를 그대로 붙여넣으세요.

```
필드이슈 대시보드 프로젝트를 이어서 작업할 거야.

먼저 아래 문서를 읽고 파악해줘.
- PRD.md (무엇을 만드는 제품인지)
- PLAN.md (다음에 무엇부터 할지)
- docs/인수인계.md (지금 상태, 미검증 항목)
- docs/결정기록.md (왜 그렇게 만들었는지)

다 읽고 나서 네가 이해한 내용을 짧게 정리해서 알려줘.
특히 "하지 않기로 한 것"이 무엇인지 확인하고 싶어.
그 다음에 뭘 할지 얘기하자.
```

정리한 내용을 보면 **제대로 이해했는지 바로 확인**할 수 있습니다.
어긋나면 그 자리에서 바로잡으세요.

## 3단계 — 화면 확인

로그인 없이 가짜 데이터로 화면만 띄워 보는 방법입니다.

```bash
node tools/makeqa.js index.html qa/index.html
node tools/serve.js qa 8093
```

`http://localhost:8093` 으로 접속합니다. 화면 위에 "가짜 데이터" 안내 띠가 뜹니다.

## 바로 쓸 수 있는 프롬프트

### 에러코드 모음집 갱신 (가장 밀린 일)

```
Z 드라이브에 모델별 화면설계서가 있어.
Z:\품질보증실\공용\품질개선팀\17. 모델별 에러코드\<모델>\

tools/codebook/README.md 에 적힌 순서대로
<모델명> 에러코드를 최신화해줘.

OCR 단계를 빠뜨리지 말고, 머리글과 팝업 코드가 다른 슬라이드가 나오면
자동으로 넘기지 말고 나한테 보여줘.
```

> DENSITY에서 이 작업으로 20개 코드가 새로 나왔습니다.
> 나머지 12개 모델은 아직 검증 전입니다.

### 기능 추가

```
PLAN.md의 2단계 항목 중 <파레토 차트>를 만들어줘.
CLAUDE.md의 검증 흐름대로 미리보기로 확인한 뒤에 결과를 알려줘.
```

### 배포 준비

```
배포할 zip을 만들어줘.
index.html, error_codes.json, 아이콘 3개만 들어가야 하고
압축 안에서 index.html이 최상위에 있어야 해.
```

### 발표자료 갱신

```
화면이 바뀌었으니 발표자료 캡처를 새로 떠서 PPT를 갱신해줘.
tools/README.md 의 캡처 방법을 쓰고, 다 만든 뒤 PowerPoint로 렌더해서
글자 잘림이 없는지 직접 확인해줘.
```

### 현재 상태 점검

```
지금 저장소 상태와 배포본이 어긋나 있는지 확인해줘.
배포 안 된 변경이 있으면 목록으로 알려줘.
```

## 넘어가지 않는 것 — 직접 하셔야 합니다

| 항목 | 이유 |
|---|---|
| Netlify 배포 권한 | 계정에 묶여 있습니다 |
| Azure 앱 등록 | 리디렉션 URI 추가는 소유자만 가능 |
| SharePoint 로그인 | AI는 사용자 계정으로 로그인하지 않습니다 |
| GitHub 로그인 | 푸시할 때 한 번 승인이 필요합니다 |

AI는 **무엇을 어디서 눌러야 하는지 안내만** 하고, 실제 로그인은 직접 하셔야 합니다.
이건 `CLAUDE.md`에 규칙으로 적어 뒀습니다.

## 아직 검증 못 한 것 — 먼저 확인하세요

실계정 로그인이 필요해 AI가 확인할 수 없었던 것들입니다.
자세한 확인 방법은 `PLAN.md` 0단계에 있습니다.

1. **편집 저장이 실제로 SharePoint에 반영되는가** (가장 위험)
2. Master Version PDF 업로드·공유
3. Azure 앱 등록 소유자
4. `error_codes.json` 공개 노출이 회사 기준에 맞는지

## 저장소에 없는 것

- `deploy/` — 배포 승인본 스냅샷 (로컬에만 있습니다)
- 발표자료 `.pptx` — `tools/ppt-build.js`로 언제든 다시 만들 수 있습니다
- 작업 중 만든 임시 폴더 — 세션이 끝나면 사라집니다. 남겨야 할 것은 저장소에 넣으세요
